# Code of Conduct

Sluice adopts the Apache Software Foundation Code of Conduct in full:

https://www.apache.org/foundation/policies/conduct

## Summary

- Be respectful and considerate in all project spaces: JIRA, mailing lists,
  pull requests, code review comments, and any real-time chat.
- Assume good faith. Disagree on technical merits, not people.
- Harassment, discrimination, and personal attacks are not tolerated.
- Give credit for others' work; don't misrepresent authorship or
  qualifications.
- Step back and let a neutral third party (once available, the ASF's
  Diversity & Inclusion committee) mediate conflicts that can't be resolved
  between the parties directly.

## Reporting

Once under ASF governance, report Code of Conduct violations to
`private@sluice.apache.org` (PPMC-only list) or to the ASF's Diversity &
Inclusion committee at `conduct@apache.org`. Until the project has ASF
infrastructure, report to the project owners directly — see
`docs/APACHE_ONBOARDING.md` for current contact points.

## Scope

Applies to all project spaces (issue tracker, mailing lists, code review,
documentation, and any official project events), and to private
communication when it pertains to project business.
